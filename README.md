# SRG+ Forms for Mac

Forms, surveys and quizzes, with the answers in your SRG+ account. Part of SRG+ One.

**Download:** https://github.com/srgplus/srgplus-forms-macos/releases/latest/download/SRG-Plus-Forms.dmg

This repository only holds the releases (the notarized DMG) and `appcast.xml`, the update feed every installed app reads
(served by GitHub Pages). The app's code lives in a private repository. More: https://srgplus.app/forms
